## 1. 业务背景与目标

### 1.1 业务背景

中小企业老板（年营收 1000 万 - 1 亿元）在日常经营中面临严峻的税务合规挑战：

- **隐性风险不可见**：无票收入、申报偏差等税务风险隐藏在账务深处，老板关心合规但不知道账是否准确。
- **缺乏主动发现工具**：目前依赖"等出事后找税务局朋友打听"，无法主动发现风险。
- **风险代价极高**：一旦被查，面临罚款、补税、滞纳金，严重的负刑事责任和税务黑名单。
- **竞品已有验证**：市场已有类似产品，客户认可度较高，说明需求被验证。

**核心问题**：中小企业老板不知道自己企业的税务风险在哪里、如何量化、优先级是什么。

### 1.2 目标

1. **税务风险可视化**：帮助老板了解自己企业的税务风险在哪里、评分是多少。
2. **销售漏斗建立**：通过低门槛工具（3000元/年）建立信任，后续用高价值服务（3-5万）放大收入。
3. **差异化定位**：用"税务局的语言"告诉客户已知的东西，而非简单的财务指标。

### 1.3 范围边界

- **本期包含**（第一阶段 + 第二阶段）：
  - 指标库管理（原子指标 / 衍生指标 / 复合指标）
  - 场景配置（风险场景的定义与参数配置）
  - 工作台（老板视角的风险总览）
  - 动态风险监控（定期检测 + 手动触发）
  - 风险报告（风险清单 + 评分 + 建议）
- **本期不包含**（第三阶段）：
  - 风险处理工作流（风险发现后的处理流程）
  - AI 深度分析（智能风险解读与预测）

## 2. 用户角色与使用场景

### 2.1 用户角色定义

| 角色 | 职责描述 | 核心诉求 |
|------|----------|----------|
| **企业老板**（宋总） | 年营收5000万的小商品商贸企业主，关心合规但缺乏税务专业知识 | 知道自己的税务风险在哪里、严不严重、怎么解决 |
| **财务公司对接人** | 负责代理客户的外账，了解客户财务数据 | 能够向客户解释风险报告内容，辅助销售转化 |
| **销售顾问** | 负责向客户演示产品、促成付费 | 销售演示时能独立操作，不需要技术团队陪同 |
| **系统管理员** | 负责配置指标库和场景 | 配置风险指标、定义检测场景、管理客户列表 |

### 2.2 典型使用场景

#### 场景A：老板查看风险总览（企业老板）
> 企业老板登录工作台，一眼看到"税务风险评分：72分，风险等级：中等"。点击查看详情，看到自己的风险清单：某类无票收入申报偏差（高风险）、供应商发票缺失（中风险）、个人所得税申报差异（低风险）。老板点击"了解更多"，看到针对每项风险的具体建议。

#### 场景B：销售远程演示（销售顾问）
> 销售顾问在拜访客户前，打开工作台，选择该客户，点击"风险检测"生成报告。演示时，客户能看到自己的风险数据，销售顾问逐一解释每项风险的含义和解决建议。客户当场表示兴趣，问能不能先把最高风险处理掉。

#### 场景C：指标库配置（系统管理员）
> 系统管理员进入"指标库管理"，新建一个复合指标"无票收入占比"，由原子指标"本期无票收入金额"和"本期总收入"计算得出。设置阈值为"无票收入占比 > 15% 则触发高风险提醒"。

#### 场景D：场景配置（系统管理员）
> 系统管理员配置"增值税异常申报"场景，设置检测规则：当期进项税额抵扣明显偏离行业平均值时触发预警。配置触发条件：自动（每月申报后检测）+ 手动（销售演示时）。

## 3. 业务流程图

### 3.1 风险检测核心流程

```
企业老板/销售顾问
       ↓
  选择企业客户
       ↓
  触发风险检测（手动 / 自动定时）
       ↓
  指标库引擎执行计算
       ↓
  场景配置匹配（是否触发风险规则）
       ↓
  生成风险报告（评分 + 清单 + 建议）
       ↓
  展示在工作台 / 导出报告
       ↓
  [可选] 跳转服务流程（3-5万解决方案）
```

### 3.2 指标库计算流程

```
原子指标（基础数据）
       ↓
  衍生指标（原子指标组合）
       ↓
  复合指标（衍生指标计算）
       ↓
  场景匹配（触发阈值 / 规则）
       ↓
  风险事件生成
```

### 3.3 管理员配置流程

```
系统管理员
       ↓
  配置指标库（原子/衍生/复合）
       ↓
  配置风险场景（规则 + 触发条件）
       ↓
  关联企业客户（分配检测场景）
       ↓
  监控检测执行状态
```

## 5. 每个功能详细规则

### 5.1 指标库管理

#### 5.1.1 指标分类

| 指标类型 | 说明 | 示例 |
|----------|------|------|
| **原子指标** | 不可拆分的最小数据单元，直接取自财务数据 | 本期无票收入金额、本期增值税申报额、期末存货金额 |
| **衍生指标** | 由多个原子指标通过简单运算（加/减/比例）组合 | 无票收入占比 = 无票收入金额 / 总收入 |
| **复合指标** | 由多个衍生指标通过复杂规则组合，支持阈值判断 | 税务风险综合评分 = f(无票收入占比, 进项抵扣偏差, 所得税税负率) |

#### 5.1.2 原子指标配置

**字段规则**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 指标编码 | VARCHAR | 是 | 全局唯一，如：TAX_001 |
| 指标名称 | VARCHAR | 是 | 如：本期无票收入金额 |
| 指标说明 | VARCHAR | 否 | 业务含义描述 |
| 数据来源 | 枚举 | 是 | 财务系统导入 / Excel上传 / API接入 |
| 数据字段 | VARCHAR | 是 | 对应财务系统中的字段名 |
| 计算周期 | 枚举 | 是 | 日 / 月 / 季 / 年 |
| 数据类型 | 枚举 | 是 | 金额 / 比率 / 数量 / 比率变化 |

**业务规则**：
1. 原子指标创建后不可删除，仅可禁用（被衍生/复合指标引用时）。
2. 同一指标编码全局唯一，重复时报错。
3. 数据来源变更时，需保留历史数据映射关系。

#### 5.1.3 衍生指标配置

**字段规则**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 指标编码 | VARCHAR | 是 | 如：TAX_DER_001 |
| 指标名称 | VARCHAR | 是 | 如：无票收入占比 |
| 父指标列表 | JSON | 是 | 引用的原子/衍生指标列表 + 运算规则 |
| 计算公式 | 文本 | 是 | 可配置的简单公式，如：(A/B)*100 |
| 结果类型 | 枚举 | 是 | 百分比 / 金额 / 分数 |

**公式配置示例**：
```
无票收入占比 = (本期无票收入金额 / 本期总收入) * 100
```

#### 5.1.4 复合指标配置

**字段规则**：

| 字段    | 类型      | 必填  | 说明                                        |
| ----- | ------- | --- | ----------------------------------------- |
| 指标编码  | VARCHAR | 是   | 如：TAX_CMP_001                             |
| 指标名称  | VARCHAR | 是   | 如：税务风险综合评分                                |
| 子指标权重 | JSON    | 是   | 各衍生指标的权重配置                                |
| 评分规则  | 文本      | 是   | 综合评分算法（可为线性加权或分段函数）                       |
| 评分范围  | 数值区间    | 是   | 如：0-100分                                  |
| 等级划分  | JSON    | 是   | 各等级的分数区间，如：90-100优秀/70-89良好/50-69中等/<50危险 |

**等级划分示例**：
```json
{
  "score_ranges": [
    {"min": 90, "max": 100, "level": "优秀", "color": "green"},
    {"min": 70, "max": 89, "level": "良好", "color": "blue"},
    {"min": 50, "max": 69, "level": "中等", "color": "yellow"},
    {"min": 0, "max": 49, "level": "危险", "color": "red"}
  ]
}
```

### 5.2 场景配置

#### 5.2.1 风险场景定义

**场景类型**：

| 场景大类 | 场景示例 | 检测逻辑 |
|----------|----------|----------|
| 增值税风险 | 进项抵扣异常、无票收入漏报、发票缺失 | 比对申报数据与财务账差异 |
| 所得税风险 | 成本费用异常、税前扣除不合规、优惠未享 | 税负率偏离行业均值 |
| 个人所得税风险 | 申报人员差异、奖金一次性发放 | 人员信息与申报信息比对 |
| 发票风险 | 发票缺失、发票作废未处理、重复报销 | 发票状态追踪 |

#### 5.2.2 触发规则配置

**字段规则**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 场景编码 | VARCHAR | 是 | 如：SCENE_001 |
| 场景名称 | VARCHAR | 是 | 如：增值税进项抵扣异常 |
| 关联指标 | JSON | 是 | 触发该场景所需的指标列表 |
| 触发条件 | 枚举 | 是 | 阈值触发 / 偏差触发 / 趋势触发 / 规则触发 |
| 阈值设置 | JSON | 条件必填 | 阈值条件，如：偏差>20% |
| 风险等级 | 枚举 | 是 | 高 / 中 / 低 |
| 风险描述 | 文本 | 是 | 该场景的风险说明，用于报告展示 |
| 建议措施 | 文本 | 是 | 针对该风险的建议处理方式 |
| 触发方式 | 枚举 | 是 | 自动 / 手动 / 两者都要 |
| 自动检测周期 | 枚举 | 否 | 月度申报后 / 季度 / 年度 |

**触发条件类型说明**：

| 触发类型 | 说明 | 示例 |
|----------|------|------|
| 阈值触发 | 指标值超过设定阈值 | 无票收入占比 > 15% |
| 偏差触发 | 指标值偏离历史均值或行业均值 | 当期税负率偏离行业均值 > 30% |
| 趋势触发 | 指标趋势出现异常变化 | 连续3个月成本增长率 > 收入增长率 |
| 规则触发 | 满足特定业务规则 | 存在已作废发票未处理 |

#### 5.2.3 场景与指标关联

**关联逻辑**：
1. 一个场景可关联多个指标（AND / OR 关系）。
2. 配置时需指定指标间的逻辑关系：
   - AND：该场景下所有指标都触发才算触发
   - OR：该场景下任意一个指标触发即算触发

### 5.4 工作台（老板视角）

#### 5.4.1 风险总览

**展示内容**：
1. **综合评分**：0-100分，数字 + 环形进度图
2. **风险等级**：优秀 / 良好 / 中等 / 危险（对应颜色）
3. **风险趋势**：近6个月评分变化折线图
4. **风险分布**：各风险类别的数量占比（饼图）

**视觉规范**：
- 评分数字突出显示，字体大而醒目
- 等级颜色语义：绿色=安全、蓝色=注意、黄色=警告、红色=危险
- 趋势图支持鼠标悬停查看月度详情

#### 5.4.2 风险清单

**列表字段**：

| 字段 | 说明 |
|------|------|
| 风险项 | 风险名称 |
| 风险类别 | 增值税 / 所得税 / 个税 / 发票 |
| 风险等级 | 高 / 中 / 低（颜色标签） |
| 关联场景 | 触发该风险的场景名称 |
| 检测日期 | 最近一次检测的时间 |
| 详情 | 展开查看具体数据和建议 |

**筛选与排序**：
- 支持按风险等级筛选（全部 / 高 / 中 / 低）
- 支持按风险类别筛选
- 支持按检测日期排序
- 支持搜索风险项名称

#### 5.4.3 风险详情与建议

**详情页面字段**：

| 区域 | 内容 |
|------|------|
| 基本信息 | 风险项名称、类别、等级、检测时间 |
| 数据明细 | 相关指标数据（如：本期待申报无票收入10万，实际入账8万，差异2万） |
| 风险解读 | 该风险的税务逻辑说明（用税务局的语言解释） |
| 建议措施 | 具体操作建议（如：尽快补开增值税发票入账，或调整本期申报） |
| 相关单据 | 触发该风险的相关单据列表（可穿透查看） |

### 5.5 风险检测

#### 5.5.1 手动检测

**触发入口**：
1. 工作台顶部"立即检测"按钮
2. 客户详情页"风险检测"按钮
3. 销售演示模式下的"生成报告"按钮

**检测流程**：
1. 选择企业客户（单选）
2. 选择检测场景（可多选，或使用该客户的预设场景）
3. 点击"开始检测" → 显示检测进度条
4. 检测完成 → 展示报告或跳转到工作台

**检测耗时**：
- 单客户全量检测 ≤ 30秒（10个场景以内）
- 超时展示进度条，不阻塞页面

#### 5.5.2 自动定时检测

**触发规则**：
1. 按配置的周期自动执行（如：每月增值税申报完成后）
2. 管理员可配置"申报完成"的事件触发（对接财务系统）或使用固定日期（每月15日）
3. 检测完成后自动更新该客户的最新风险评分和等级

**执行记录**：
- 每次执行记录：执行时间、客户数、成功数、失败数
- 失败时记录原因（如：数据源连接失败）

#### 5.5.3 检测历史

**记录字段**：

| 字段 | 说明 |
|------|------|
| 检测ID | 系统自动生成 |
| 检测时间 | 精确到分钟 |
| 触发方式 | 手动 / 自动 |
| 触发人 | 手动触发时记录操作人 |
| 客户数 | 本次检测涉及的客户数 |
| 风险评分 | 本次检测的综合评分 |
| 风险等级 | 高 / 中 / 低 |
| 风险项数量 | 各等级的数量统计 |
| 操作 | 查看报告 / 重新检测 |

### 5.6 风险报告

#### 5.6.1 报告生成

**报告内容结构**：

```
财小哥税务风险报告
客户：XXXX有限公司        生成日期：2026-05-29    检测周期：2026年5月

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
一、综合评分
   ┌─────────────────────────┐
   │     风险评分：72分       │
   │     风险等级：中等       │
   │     检测时间：2026-05-29 │
   └─────────────────────────┘

二、风险概览
   高风险：1项    中风险：3项    低风险：2项

三、风险详情
   [高风险] 增值税无票收入漏报
   - 风险描述：本期存在2万元无票收入未申报...
   - 数据明细：申报金额8万 vs 入账金额10万
   - 建议：尽快补充发票或调整申报

   [中风险] 企业所得税税负率偏低
   - ...

四、附录
   - 指标说明
   - 风险等级定义
   - 联系我们
```

#### 5.6.2 报告导出

**导出格式**：
- **PDF**：带企业Logo区域、页眉页脚、适合发给客户
- **Excel**：适合内部分析，包含明细数据表格

**导出权限**：
- 仅管理员和销售顾问可导出
- 导出记录操作日志（审计）

#### 5.6.3 报告分享

**分享方式**：
1. **链接分享**：生成临时链接（有效期7天），可发给客户查看（只读）
2. **邮件分享**：直接发送报告PDF到客户邮箱

**分享记录**：
- 记录分享时间、分享人、接收人、链接有效期

## 7. 异常场景与边界处理

### 7.1 数据层异常

| 异常场景 | 触发条件 | 系统处理 |
|----------|----------|----------|
| **财务数据缺失** | 客户当月数据未导入，指标无法计算 | 跳过该指标，标注"数据缺失"，不影响其他指标；报告提示"部分数据未更新" |
| **指标计算超时** | 复合指标涉及大量数据，计算超时（>60秒） | 标记为"计算超时"，展示已计算的部分指标 |
| **数据来源连接失败** | 配置的API/数据库连接失败 | 记录失败日志，自动重试3次；重试失败后发送管理员告警 |
| **历史数据不一致** | 客户的财务数据发生追溯调整，历史检测结果不再匹配 | 不自动更新历史报告，保留原结果；新检测使用最新数据 |

### 7.2 场景配置异常

| 异常场景 | 触发条件 | 系统处理 |
|----------|----------|----------|
| **循环依赖** | 复合指标A依赖B，B依赖A | 保存时拦截，提示"检测到循环依赖，请检查指标关系" |
| **除零错误** | 衍生指标公式中出现除数为0（如：收入为0） | 计算结果置为NULL，报告标注"计算异常" |
| **阈值越界** | 配置的阈值超出指标正常范围 | 保存时提醒"阈值超出指标正常范围（如：比例>100%）"，但不拦截 |
| **场景冲突** | 两个场景配置了冲突的触发条件，导致同一指标同时触发 | 保留两个场景，各自独立展示；在报告中标注"可能存在重叠" |

### 7.3 报告层异常

| 异常场景 | 触发条件 | 系统处理 |
|----------|----------|----------|
| **报告生成超时** | 客户数据量大，PDF生成超时（>30秒） | 先展示HTML预览，引导用户稍后刷新下载 |
| **分享链接失效** | 客户打开链接时已超过有效期 | 提示"链接已失效，请联系顾问重新获取" |
| **并发检测冲突** | 同一客户同时触发多次检测 | 合并为一次检测，提示"检测进行中，请稍候刷新" |

### 7.4 边界条件

1. **最大客户数边界**：单系统支持 10,000 个客户账号。
2. **最大指标数边界**：单系统支持 500 个指标（原子+衍生+复合）。
3. **最大场景数边界**：单系统支持 200 个风险场景。
4. **检测并发边界**：同一客户同一时间只能执行一次检测（数据库乐观锁）。
5. **报告存储边界**：报告PDF存储上限 50MB/份，超出时压缩或提示。

## 8. 非功能性需求

### 8.1 性能需求

| 场景 | 指标 | 验收标准 |
|------|------|----------|
| 风险评分计算 | 响应时间 | 单客户10个指标计算 ≤ 3秒 |
| 风险检测全流程 | 响应时间 | 单客户全量检测（10个场景）≤ 30秒 |
| 工作台加载 | 响应时间 | 首页加载（含评分+趋势+清单）≤ 2秒 |
| 报告生成PDF | 处理时间 | 10项风险PDF导出 ≤ 10秒 |
| 并发检测 | 系统容量 | 支持20个用户同时发起检测无阻塞 |

### 8.2 数据安全与权限

| 维度       | 需求                                      |
| -------- | --------------------------------------- |
| **功能权限** | 企业老板只能看自己的风险报告；销售顾问可看分配给自己的客户报告；管理员可看全部 |
| **数据权限** | 销售顾问只能访问自己负责的客户数据                       |
| **操作日志** | 所有风险检测、报告导出、场景配置操作记录操作人、时间、IP           |
| **敏感数据** | 财务原始数据需加密存储；报告导出需水印                     |

### 8.3 可靠性与容错

1. **检测任务可靠性**：自动检测任务失败后自动重试3次，间隔5分钟；重试失败后记录失败原因并告警。
2. **数据备份**：每日凌晨自动备份指标库、场景配置、客户数据；保留30天。
3. **灾难恢复**：RPO ≤ 24小时，RTO ≤ 4小时。

### 8.4 兼容性与扩展性

1. **浏览器兼容**：Chrome ≥ 90、Edge ≥ 90、Safari ≥ 14、Firefox ≥ 88。
2. **移动端适配**：工作台报告查看需适配移动端浏览器（H5响应式）。
3. **接口预留**：
   - 预留与财务系统对接的API（接收财务数据）
   - 预留与税务申报系统对接的API（获取申报数据）
4. **场景扩展**：支持后续新增场景类型，无需修改底层架构。

### 8.5 易用性

1. **新手引导**：首次进入工作台时，弹出引导提示："首次使用建议先完成企业信息配置，然后进行首次风险检测"。
2. **快捷操作**：
   - 工作台支持"一键检测"按钮，快速触发全量检测
   - 风险清单支持"导出Excel"批量操作
3. **智能提示**：
   - 检测完成后提示"本次检测发现3项风险，较上次增加1项高风险，建议优先处理"
   - 报告分享时提示"链接有效期7天，是否发送邮件通知客户"
